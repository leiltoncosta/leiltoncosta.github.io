Configuração inicial
Para o sistema funcionar, informe os dados do seu projeto no Supabase.

No painel do Supabase vá em Project Settings → API e copie:
• Project URL (algo como https://xxxx.supabase.co)
• a chave anon / public

Antes disso, rode o arquivo schema_supabase.sql em SQL Editor → New query.
Essa chave é pública por natureza — quem protege os dados é o login e as regras de acesso do banco.
